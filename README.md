# Good Burrow website

This public repository contains Good Burrow's product homepage, the Burrowmarks
marketing and license pages, and product pages with fictional sample exports
for Social Library and Chat Library. The Anthora page is prepared locally and
remains marked as awaiting final approval until checkout and delivery have
passed a real test.

The Browser Extension License Kit was withdrawn from sale on August 17, 2026.
Its source and customer package remain in the independent product repository,
but it is not listed on this site.

The discontinued managed-website sales pages and demonstrations are not part of
the public site.
