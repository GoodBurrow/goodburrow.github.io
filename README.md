# Good Burrow website

This public repository contains Good Burrow's product homepage, the Burrowmarks
marketing and license pages, and the Extension License Kit information page.
It also contains product pages and fictional sample exports for Social Archive
and Chat Library. The Anthora page is prepared locally and remains marked as
awaiting final approval until checkout and delivery have passed a real test.

The discontinued managed-website sales pages and demonstrations are not part of
the public site.
