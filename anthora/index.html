Before buying

  • SystemRequires an Apple silicon Mac, M1 or newer, running macOS 14 Sonoma or later.
  • Media sourcesWorks with readable folders, external drives, and mounted network shares. Cloud-only placeholders must be downloaded first.
  • FormatsImages: JPG, JPEG, PNG, HEIC, HEIF, WebP, GIF, TIFF, and TIF. Videos: MOV, MP4, and M4V.
  • Photos.appAnthora does not read a Photos.app library directly.
  • First launchThis direct download is not notarized by Apple. The included guide explains the one-time macOS Open confirmation. Gatekeeper does not need to be disabled.
  • Analysis limitsAutomatic matches and quality signals require review. Semantic language search, best-shot grouping, and crop-aware matching are not included in version 1.0.0.
  • PurchaseThe purchase includes the current app and self-service documentation. Setup, customization, consultations, phone service, response times, and guaranteed future updates are not included.
  • RefundsDownloaded software is normally final except where required by law or the seller of record's checkout policy.

Private server mode is optional.

Local use is the default. Advanced users can run the included server on a Mac they control and connect through a private network such as Tailscale. Good Burrow does not host the server or provide network setup.
