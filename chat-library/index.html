Before you buy

What the app opens

  • Current systemDesigned for macOS 14 or newer.
  • First launchThis direct-download release is not notarized by Apple. If macOS blocks it, open System Settings, choose Privacy & Security, and click Open Anyway beside Chat Library.
  • Supported inputA ChatGPT data-export ZIP or extracted folder containing conversations.json.
  • Conversation branchesThe current branch is shown first. Saved alternate branches appear as separate entries.
  • Export limitsThe app displays what is present in the downloaded export. It cannot retrieve information that is not in those files.
  • What the purchase includesThe current app version and its included instructions.
